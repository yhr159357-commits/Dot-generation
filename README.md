# 点构 · DOT STUDIO

浏览器本地波点素材工作台：形状、排列、大小渐变、颜色与透明度、自定义尺寸、自由绘制软边蒙版，支持 PNG / SVG 导出和配置保存。

## GitHub Pages 发布

将 index.html、.nojekyll 和此 README.md 上传到仓库 main 分支根目录。

打开仓库 Settings → Pages，在 Build and deployment 下选择 Deploy from a branch，然后选择 main 和 /(root)，点击 Save。

GitHub Free 使用公开仓库。发布完成后，以 Pages 设置返回的地址为准，不要把仓库地址当作网站地址。

HTTPS 下支持系统保存窗口的浏览器可选择文件保存位置；不支持的浏览器使用下载提示。

网站不依赖外部脚本、字体、CDN 或后端。GitHub Pages 的中国大陆访问情况需实际测试，发布成功不代表国内所有网络均可访问。

所有用户设计数据保存在当前浏览器；从本地文件迁移到线上地址前，可先保存配置并在新页面导入。
