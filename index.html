从点到面，轻松创作

在右侧调整波点，画布会即时更新。点击「蒙版绘制」，直接在画布上用黑色画笔擦除、白色画笔恢复。蒙版只作用于波点，背景保持完整。

大小渐变由起始尺寸、结束尺寸和方向共同决定。渐变起点和终点控制变化覆盖的区域；结束尺寸为 0 时，波点逐渐消失。

「透明背景预览」只控制画布显示；导出时由「同时导出背景」决定是否包含背景。取消勾选后 PNG、SVG 和复制的 SVG 代码都使用透明背景。

画笔透明度为 100% 时完全作用，0% 时不绘制；低透明度可以轻涂，多次抬笔后叠加。蒙版使用矢量笔迹，PNG / SVG 均保留擦除、柔边和每笔透明度。每次完整笔画可撤销，配置文件会保留蒙版；调整画布尺寸时，蒙版会按比例适配。

Ctrl / ⌘ + Z 撤销，Ctrl / ⌘ + Shift + Z 重做。B 开关画笔，X 切换黑白，[ / ] 调整画笔大小。
